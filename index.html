How I build

Outside client work, I build open source the same way: I start from a real production requirement and turn it into a reusable solution that's cheap to run and reliable enough to trust. The systems thinking is part of the deliverable:

  • Cost first: start from the unit economics and size down to the smallest machine that measurably works.
  • Reliability you can prove: an acceptance check for every requirement, and a go-ahead gate before anything ships.
  • Evidence before decisions: benchmarks, written down with the trade-off and who decided.
  • Secure and maintainable by default: localhost-only services, no stored credentials, pinned versions, one supported platform.

docling-batch-extract

Batch PDF → Markdown for RAG search on one CPU-only server, using docling-serve. Built for legal and claims-insurance documents (including scans) as a low-cost alternative to cloud OCR APIs. Documents never leave your server.

  • Tested on Ubuntu LTS
